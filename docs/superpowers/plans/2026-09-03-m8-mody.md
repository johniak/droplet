# M8 — Mody jako część gry: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pliki w `<system>/<Gra>/mods/` są rozpoznawane jako mody, pobierane razem z grą na telefon i pokazane w aplikacji z podpowiedzią instalacji; Switch rozpoznaje DLC po title id.

**Architecture:** Skaner nadaje rolę `mod` plikom bezpośrednio w `mods/`, a rozpakowane podkatalogi zgłasza jako jeden wpis „do uporządkowania”. API nie zmienia kształtu (nowa wartość `role`, ścieżka względna z prefiksem `mods/`). Aplikacja dostaje `FileRole.mod`, istniejąca selekcja i stan instalacji obejmują mody automatycznie, ekran gry dostaje grupę „Mods” z podpowiedzią i „Copy path”.

**Tech Stack:** Django 6 + DRF (backend, pytest, 100% coverage), Flutter + Riverpod 3 (app, 100% line coverage), Docker compose e2e, Android emulator e2e.

**Spec:** `docs/superpowers/specs/2026-09-03-m8-mody-design.md`

def parse_switch(stem: str) -> SwitchInfo:
    tid_m = _TID.search(stem)
    tid = tid_m.group(1).upper() if tid_m else None
    ver_m = _VER.search(stem)
    version = ver_m.group(1) if ver_m else ""
    suffix = tid[-3:] if tid else None
    if _DLC.search(stem):
        role = "dlc"
    elif _UPD.search(stem) or suffix == "800":
        role = "update"
    elif suffix is not None and suffix != "000":
        # Title id spoza rodziny base/update: 13. cyfra podbita o 1 i licznik
        # w końcówce (…5001, …5002) — tak Nintendo numeruje DLC.
        role = "dlc"
    else:
        role = "base"
    return SwitchInfo(title_id=tid, role=role, version=version)
```

MODS_DIR = "mods"


def _mod_kind(path: Path, folder: Path) -> str | None:
    """`"file"` dla pliku bezpośrednio w `<gra>/mods/`, `"nested"` dla pliku
    głębiej w `mods/` (rozpakowany mod), `None` poza `mods/`."""
    rel = path.relative_to(folder).parts
    if len(rel) < 2 or rel[0].lower() != MODS_DIR:
        return None
    return "file" if len(rel) == 2 else "nested"
```

3. Na początku `_group_folder`, tuż po `files = sorted(...)` i przed `if not files`, odfiltruj mody:

```python
    files = sorted(p for p in folder.rglob("*") if p.is_file() and not _hidden(p, root))
    mods = [p for p in files if _mod_kind(p, folder) == "file"]
    nested: dict[Path, int] = {}
    for p in files:
        if _mod_kind(p, folder) == "nested":
            top = folder / p.relative_to(folder).parts[0] / p.relative_to(folder).parts[1]
            nested[top] = nested.get(top, 0) + p.stat().st_size
    files = [p for p in files if _mod_kind(p, folder) is None]
    if not files and not mods and not nested:
        return None
```

    return GlassPanel(
      margin: const EdgeInsets.only(top: 2, bottom: 10),
